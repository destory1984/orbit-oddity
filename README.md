# Orbit Oddity 도킹 시험작 (0단계)

회전하는 우주 정거장에 배를 도킹하는 브라우저 시험작이다. 기획서 0단계의 목표인 "도킹이 재미있는가"를 확인하려고 만들었다.

## 실행

`index.html` 을 브라우저로 연다. three.js 0.160.0 과 Rapier 0.12.0 을 jsDelivr에서 불러오므로 인터넷 연결이 필요하다.

글꼴은 Space Oddity와 같은 Pretendard를 `fonts/` 에 실어 두었다. 크롬은 파일을 바로 열면(file://) 글꼴 파일을 막아 맑은 고딕으로 보인다. 제 글꼴로 보려면 이 폴더에서 `python -m http.server 8765` 를 띄우고 http://127.0.0.1:8765/combat.html 로 연다. 출처는 THIRD-PARTY.md 에 적었다.

## 조작

- W/S 앞뒤 추력, A/D 좌우, R/F 위아래
- 방향키 기수 상하·좌우, Q/E 롤
- 마우스: 화면을 누르면 커서가 잠기고, 움직이면 방향을 튼다. 왼쪽 버튼 전진, 오른쪽 버튼 후진, Esc 로 잠금을 푼다
- Z 보조 비행 켜기/끄기, C 시점 전환, T 처음부터

## 규칙

- 정거장은 60초에 한 바퀴 돈다. 입구는 30 m × 12 m, 배 날개 폭은 12 m다. 보조 비행을 켜면 정거장 400 m 안에서 롤을 저절로 맞춘다. X 를 누르면 도킹 컴퓨터가 알아서 들어간다.
- 입구 안쪽 15 m 이상 들어가 정거장 기준 상대 속도 3 m/s 아래로 1.5초 버티면 도킹이 끝난다.
- 부딪히면 튕겨 나올 뿐 배는 부서지지 않는다.
- 정거장은 지구 고도 400 km(국제우주정거장과 같은 높이)에 있고, 지구 반지름은 6,371 km 실제 값을 쓴다.

# 전투 시험작

`combat.html` 을 브라우저로 연다. 엘리트(1984)처럼 정거장 주변에서 적기와 싸운다.

- 적기는 무리로 온다. 적 속도는 초당 40 m다. 첫 무리는 2척이고, 무리마다 1척씩 는다. 무리를 다 잡으면 미사일 2발을 받는다(최대 6발).
- 레이저: 스페이스. 마우스 왼쪽 버튼은 방향 조종에만 쓴다. 조준선 고리(약 4°) 안에 적이 들어오면 고리와 적 테두리가 초록으로 바뀌고 레이저가 그 적에게 휘어 맞는다. 사거리 1,200 m, 한 발에 8씩 깎는다.
- 미사일: G 또는 마우스 오른쪽 버튼. 조준선 쪽에 가장 가까운 적을 쫓아가 70을 깎는다.
- 내 배는 방패 60, 선체 100이다. 방패는 2초 동안 안 맞으면 초당 6씩 찬다.
- 적은 선체가 30% 아래로 떨어지면 달아난다.
- 마우스 조종은 Freelancer(2003) 방식이다. 커서가 가리키는 쪽으로 배가 돌고, 레이저도 커서 쪽(기수에서 20° 안)으로 나간다. 커서가 화면 가운데에서 멀수록 빨리 돈다. 가운데 점선 원 안에 커서를 두면 돌지 않고, 커서가 창 밖으로 나가도 멈춘다.
- V 를 누르면 움직인 만큼만 도는 방식(커서 잠금)으로 바뀐다. 다시 누르면 돌아온다.
- 스마트폰: 화면 왼쪽 절반을 끌면 추력·좌우 이동 막대, 오른쪽 절반을 끌면 조준점이 움직인다. 손을 떼면 조준점은 가운데로 돌아온다. 적이 고리 안에 들면 레이저를 저절로 쏜다. 미사일·다시·소리 단추가 오른쪽 아래에 있다.
- 스마트폰 "기울이기" 단추를 누르면 폰을 기울여 조준한다. 켠 순간의 자세가 기준이다. 아이폰은 권한을 묻는다.
- 배 겉모습은 그림 파일 없이 코드로 그린다(패널선, 리벳, 줄무늬, 기번 OO-01). C 를 누르고 있으면 배 둘레를 돌며 볼 수 있다.
- 엔진 불꽃은 추력에 따라 길어진다. 좌우·상하 이동, 후진, 회전할 때는 반대쪽 자세제어 분사구에서 가스가 뿜어 나온다.
- P 나 Esc, 또는 화면 위 가운데 단추로 멈춘다. 창을 벗어나면 저절로 멈춘다.
- M 으로 소리를 끄고 켠다. 소리는 파일 없이 Web Audio로 만든다.
- 화면 아래 둥근 레이더는 엘리트식이다. 타원은 내 배의 수평면이고, 막대 길이는 위아래 높이다. 빨강은 적, 파랑은 정거장, 노랑은 미사일이다.
